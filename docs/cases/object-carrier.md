# Case: an object carrier instead of a universal safe rectangle

## Specific problem

A fixed left-safe title rectangle can avoid a face but still look pasted on. The task is to make title placement explainable by the image structure without inventing a platform-performance claim.

## Input

- A repository board from `assets/layout-schemes/03-object-carrier-v17.jpg`;
- a matching ordinary comparison board and debug board;
- a visual brief naming the main idea, required title, forbidden zones, and permitted style.

## Method

1. Identify an actual carrier such as a paper, screen, whiteboard, or workbench region.
2. Protect the face, hands, key tool, and essential evidence area with explicit forbidden zones.
3. Anchor the title to the carrier or its readable edge; do not fabricate a carrier merely to hold text.
4. Review geometry and aesthetic coherence separately, retaining a failed variant when the carrier is too weak.

## Reproducible output

```sh
node scripts/check-package.mjs
```

Open the layout-scheme image and a corresponding debug panel. The reproducible result is the local package check and an annotated placement decision; no publishing action is part of this case.

## Evidence

The layout sample, versioned board, debug board, and written rule can evidence that a placement hypothesis was documented and reviewed.

## Unsupported conclusions

They do not establish copyright clearance beyond this repository's asset statement, platform compliance, publication, user preference, clicks, saves, follower growth, or revenue.

## Three-minute exercise

Choose one title region in the sample. State its carrier, its nearest forbidden zone, and one reason it remains readable. If there is no real carrier, select a different layout family rather than forcing text into that region.
